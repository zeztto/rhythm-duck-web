# 리듬 덕

키보드와 터치로 플레이하는 세 레인 리듬 게임입니다. Phaser가 오리·홀드·폭탄을 직접 그리며, WebAudio oscillator로 작성한 **132 BPM 한 곡 「오리의 박자」**를 재생합니다. 외부 녹음, 이미지, 폰트 파일이나 음원 스트리밍은 사용하지 않습니다.

## 실행

Node.js 26과 npm이 필요합니다.

```sh
npm ci
npm run dev
```

`http://127.0.0.1:44908`에서 엽니다. 소리는 시작 버튼 또는 키 입력 뒤에 활성화됩니다. production build를 확인하려면 다음을 실행합니다.

```sh
npm run typecheck
npm test
npm run build
npm run preview
npm audit
```

개발 서버와 preview는 같은 포트를 사용하므로 하나만 실행합니다. 기본 서버는 loopback에만 연결됩니다. 웹사이트로 배포할 때는 `dist/`를 정적 호스팅에 올리고 HTTPS를 사용하세요. 이 저장소의 CI는 배포하지 않습니다.

## 조작

| 동작 | 입력 |
| --- | --- |
| 왼쪽 / 가운데 / 오른쪽 | Q / W / E 또는 ← / ↓ / → |
| 모바일 입력 | 화면 아래 세 터치 패드 |
| 시작 | 시작 버튼 또는 Enter |
| 결과 뒤 재시작 | 다시 시작 버튼 또는 Enter |
| 전체화면 | F, 지원하는 브라우저에서만 |

일반 오리는 판정선에 맞춰 누릅니다. 초록 홀드는 끝까지 유지하며 황금 오리는 피버를 더 채웁니다. 빨간 원 안의 X는 폭탄이므로 누르지 마세요. 판정 오차는 정확 ±45 ms, 좋음 ±90 ms, 성공 ±140 ms입니다. 놓침·홀드 중단·폭탄은 체력을 줄입니다. 피버 중 점수 배율은 2배입니다. 체력이 소진되거나 곡이 끝나면 실제 플레이 결과를 표시합니다.

입력 보정은 −150~150 ms, 음량은 0~100%로 조정할 수 있습니다. 싱크 측정은 8박을 재생합니다. Q/W/E를 박자에 맞춰 4회 이상 누르면 평균 입력 오차로 보정값을 계산합니다. 장치·Bluetooth·브라우저의 전체 지연을 정밀 측정하는 도구는 아닙니다.

최고 점수·보정·음량은 이 사이트의 `localStorage` 한 key에만 저장합니다. 저장 권한·용량 오류 또는 손상·잘못된 형식의 설정을 발견하면 해당 원문을 덮지 않고 저장을 차단합니다. 현재 플레이와 설정 조정은 메모리에서 계속되며 화면에 안내합니다. 매 저장 직전에도 현재 key를 다시 검사합니다. 차단 상태는 이번 페이지 실행 동안 유지되며 자동 초기화·삭제하지 않습니다. 계정, 서버 저장, 순위표, 결제, 외부 분석 요청은 없습니다. 포커스를 잃으면 누르고 있던 레인을 해제합니다. 곡은 자동 일시정지되지 않습니다.

## 검증 범위

`tests/`는 판정 경계, 홀드·폭탄·피버, 전체 작성 chart의 결과 도달, HP 종료, 시간 역행·비유한 값, 동시 오디오 시작, 재시작 초기화, 저장 실패를 검증합니다. Controller 테스트의 audio double은 상태 전이를 격리하기 위한 것으로, 실제 브라우저의 소리 출력 검증을 대신하지 않습니다. production에는 시간을 이동하거나 승리시키는 전역 함수를 노출하지 않습니다.

실제 브라우저 검증과 자동 회귀의 구분은 [검증 문서](docs/validation.md)에 기록합니다. WebAudio와 Canvas를 지원하는 최신 데스크톱·모바일 브라우저가 대상이며, 오디오 자동재생 제한·전체화면 지원은 브라우저마다 다릅니다. Phaser 단일 bundle은 약 1.23 MB(압축 전)이므로 첫 다운로드 비용이 있습니다.
